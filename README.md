# Lady Flower — demo comercial

Demo estática pronta para GitHub e Netlify. Não requer instalação nem processo de build.

## Publicar no Netlify

1. Carregar esta pasta para um repositório GitHub.
2. No Netlify, escolher **Add new project → Import an existing project** e selecionar o repositório.
3. Publicar sem comando de build. O ficheiro `netlify.toml` já define a pasta de publicação.

## Antes de apresentar

- Substituir as imagens provisórias (Unsplash) pelas fotografias reais em `index.html`.
- Confirmar morada completa, dias/horários, zona/custo de entrega e canal preferido de encomendas.
- Trocar o `tel:` por WhatsApp, caso seja esse o contacto escolhido pela loja.

As informações não confirmadas aparecem explicitamente como “a confirmar”, para não serem apresentadas como factos.
